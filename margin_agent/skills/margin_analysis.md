# Margin Analysis Skill

When investigating margin deterioration:

1. Compare margin percentage across the requested periods.

2. Compare revenue:
   - Did revenue decrease?
   - Did selling price appear to decrease?

3. Compare cost:
   - Did total cost increase?
   - Did cost increase despite lower unit volume?

4. Compare units:
   - Determine whether lower volume contributed to lower total margin.

5. Calculate:
   - absolute margin change
   - margin percentage change
   - revenue change
   - cost change

6. Never invent causes that are not supported by the returned data.

7. Clearly separate:
   - observations
   - likely explanation
   - additional data needed
8. DATA FRESHNESS RULE

    For any question requiring company data:
    - Never treat prior conversational values as current evidence.
    - Always retrieve current data through the appropriate data tool.
    - Session history may be used only to preserve entities, filters,
        comparison periods, and user intent.
    - Numerical business facts from previous turns must be revalidated
        through tools before answering.

If the supplied data is insufficient to establish the reason,
say what additional data would be required.
