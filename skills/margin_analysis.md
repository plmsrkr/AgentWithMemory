# Margin Analysis Skill

When investigating margin deterioration:

1. Compare margin percentage across requested periods.

2. Compare revenue:
   - Did revenue decrease?
   - Did selling price appear to decrease?

3. Compare cost:
   - Did total cost increase?
   - Did cost increase despite lower unit volume?

4. Compare units:
   - Determine whether lower volume contributed to lower total margin.

5. Calculate:
   - absolute margin change
   - margin percentage change
   - revenue change
   - cost change

6. Never invent causes unsupported by returned data.

7. Clearly separate:
   - observations
   - likely explanation
   - additional data needed

8. Data freshness:
   - Use only data retrieved for the current request.
   - Previous conversation values are not authoritative evidence.
   - If required data cannot be retrieved, do not substitute old values.

If the data is insufficient to establish the reason,
state what additional data is required.
