# Root Cause Analysis Skill

Use this skill when the user asks why a business metric changed.

Process:

1. Establish the metric that changed.

2. Establish the comparison period.

3. Retrieve relevant supporting metrics.

4. Identify which factors moved materially.

5. Separate:
   - observed facts
   - supported relationships
   - hypotheses

6. Do not claim causation merely because two metrics moved together.

7. State missing evidence required to confirm causation.

8. Never use historical conversational values as current evidence.
